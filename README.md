# Лендинг центра «Берег»

Адаптивная HTML/CSS/JavaScript-вёрстка макета Figma, узел `5:3047`. Порядок секций сохранён: в исходном макете блок «Когда стоит обратиться» расположен перед первым экраном.

## Просмотр

Нужен Node.js 20 или новее. Выполните `npm start` и откройте http://127.0.0.1:4173. Можно также открыть `index.html` напрямую. Зависимости устанавливать не нужно.

## Файлы

- `index.html`, `styles.css` — полная разметка и оформление из макета.
- `responsive.css` — адаптивные сетки и состояния элементов.
- `app.js` — мобильное меню, навигация, FAQ, диалоги и проверка формы.
- `assets/` — локальные исходные изображения и SVG из Figma.
- `design-reference.txt`, `build.mjs` — исходные данные и воспроизводимая сборка разметки и базовых стилей (`npm run build`). Tailwind и React не требуются.

## Перед публикацией

Подключить серверный обработчик формы, предоставить политику и реквизиты, реальные ссылки на мессенджеры и полный состав команды. Сейчас форма не отправляет и не хранит данные и явно сообщает об этом. Дополнительные ответы FAQ нужно согласовать с центром. Шрифты Lora и Manrope загружаются из Google Fonts; фотографии и иконки локальные.
